# Website

Fullscreen animated single-page website workspace.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- GSAP

## Current stage

The first stage contains a fullscreen hero with:

- hidden native scrollbar
- fixed black background
- top-left logo placeholder
- top-right expandable menu
- centered animated hero copy
- glass-style word container
- scroll cue icon
- GSAP intro timeline
- GSAP scroll timeline with black transition layer

## Development

```bash
npm install
npm run dev
```
